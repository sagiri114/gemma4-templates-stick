## 和大纲旧数字不同的地方

1. **分辨率（已更正）**。大纲原写"80% 功效需约 7–8 点，真实差 5 点时检出概率 40–70%"。旧模拟给每题加同样的 δ，36 道每次都解出的题被截在 1，实际平均差只有标称值的七成左右。现在改为按截断后的真实平均差模拟：125 题 × 2 遍时，真实差 5 点的检出概率是 0.58–0.74，80% 功效需要约 6–6.5 点。用 11 个实际全量比较的区间半宽（平均 4.4 点）换算，结果是 6.3 点。要确认 3 点，每题约需 8 遍；确认 2 点，约需 16 遍。
2. **同一题内的中毒影响**。10 个配置合并后，同时有中毒和未中毒运行的题共 88 道，两者的解出率分别为 0.29 和 0.36，差 6.9 点；base 单独看是 0。把这些中毒运行全部换成同题未中毒运行的解出率，总解出率最多提高约 0.7 点。这是观察关联，不是因果上界（第五轮 README 已指出）。
3. **碰额度**。10 个配置里有 37–46% 的运行碰到时间或调用额度。碰到额度的运行解出率为 6–21%，没碰到的为 55–61%，其中混有题目难度的影响。

## 口径

- **配对比较**：与 `主赛/02_本地评测/scripts/summarize.py` 相同。只统计 status=ok。每题先对各遍取平均，再按题配对 bootstrap：`random.Random(0)`，5000 次，取排序后第 125 和第 4875 个值。第七轮报告写的是线性分位数，所以两种都算：只有 T2048 两遍之差的下端不同（−4.8 对 −4.0），其余一致；21 个报告值都与 summarize.py 的取法一致。
- **中毒**：一次运行里第一次 edit_file 缺必填参数（工具返回含 "mandatory input parameters are not present"）。"之前"包含这第一次失败本身，"之后"是同一运行里其后的 edit_file。
- **功效模拟**：每题成功率取经验值，有两种估计。c01b6 用 C01b 三次全量（每题 6 次）；pool20 用 10 个全量配置合并（每题 20 次），只在各配置没有真实差别时才合理。候选对每题加同一个平移量，超过 1 的截到 1，平移量用二分法定到截断后的平均差恰为目标值。"检出"指模拟差值超过零假设分布的 97.5% 分位，等价于双侧 95% 区间不含 0。numpy 随机种子 0，每格 4000 次。
- 小门禁的题目是按风险挑的，只有 8–40 题，不并入分辨率结论。
